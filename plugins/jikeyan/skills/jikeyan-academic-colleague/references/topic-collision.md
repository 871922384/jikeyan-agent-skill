# 选题撞题与注册库核查

用于用户问“这个题有没有人做过”“要不要先注册”时。`check_topic_collision` 只负责查 ClinicalTrials.gov 与 PubMed 综述，给出检索式和命中；它不下结论，PROSPERO 等注册库不在检索范围内。

## 操作步骤
1. 先确认用户已配置自己的 `JIKEYAN_CONTACT_EMAIL`。未配置时工具会直接报错，请用户用自己的邮箱，不要代填或借用别人的邮箱。
2. 与用户一起拟出候选题名、关键词和概念分组，再调用 `check_topic_collision`。只传题名和关键词，不传患者信息，未发表的敏感细节请用户斟酌。
3. 如实转述：各来源命中数、检索式、检索日期、来源署名。零命中不等于没人做过；命中多也不等于撞题，逐条请用户判断。不替用户给“能做 / 不能做”的结论。
4. 如果是系统综述或荟萃分析类选题，告诉用户：通常还要看 PROSPERO 等注册库有没有同题注册。这是一个知识点，不是强制步骤。

## 关于 PROSPERO
- 工具不访问 PROSPERO，结果里的 `not_searched` 会列出它。
- PROSPERO 的使用条款对自动化访问和商业用途有限制，具体以其官网当前条款为准（入口：https://www.crd.york.ac.uk/prospero/）。因此不要自行写脚本批量抓取它。
- 是否检索、怎么检索，由用户自己决定并自行负责：可以让用户在浏览器里手动查，Agent 把检索词整理给用户即可。用户明确要求你协助查看时，先把上面这一点告诉用户，再按用户的决定办。
- 用户没回答之前，把这一项记为“待核实”，不要写成“已查无同题注册”。

## 示例：向用户转述
用户：我想做枸橼酸抗凝在 CRRT 的系统综述，有人做过吗？

Agent：我用你的邮箱在本机查了 ClinicalTrials.gov 和 PubMed 综述，检索式和日期见下表；命中的前几条和你的题相关，需要你判断是否同题。PROSPERO 我没有查：它的使用条款对自动化访问有限制，所以我把检索词整理给你，你可以自己去网站上搜，搜完告诉我结果。在你确认前，这一项我记为“待核实”。

## 常见坑
把零命中说成“没人做过”；把工具的检索结果说成选题结论；代用户使用他人邮箱；用脚本批量抓取注册库；用户没确认就把“PROSPERO 无同题”写进计划或节点。
